- ./packages 폴더와 ./manifest.yaml 파일 참조
- agents와 skills가 plugins로 변경 됨
- manifest plugin들은 packages/plugins 폴더 안에 <name>으로 폴더화 되어 있음
- manifest target이 있다면 해당 타겟만 설치가 가능하다 커맨드 라인에서 all일
  경우에도 해당 타겟에만 설치
- 플러그인 이름 또는 alias를 전달 받아서 해당 플러그인을 설치
- install시 --all 플래그를 입력하지 않거나 플러그인 이름을 입력하지 않는다면
  이름을 입력하고 메세지를 출력한다.
- chain이 있다면 해당 플러그인도 같이 설치한다.
- _init 폴더와 init-tree.yaml을 제외한 폴더안에 있는 모든 것들을 각 타겟에 맞게
  복사 (최초 1회만 설치 이후 업데이트 할 때는 설치를하지 않는다)
  - init-tree 커맨드를 만들어서 재설치 가능하게한다.
  - init-tree.yaml을 참고해서 프로젝트 폴더에 복사 (workspace 프로젝트 폴더)
  - _meta.meta 데이터는 복사하지 않는다
- packages/plugins/<name>/폴더에 .codex, .agents 같은 폴더가 있다면 각 타겟
  설치시 또는 update시 같이 복사를 해준다.
  - packages/plugins/<name>/.codex/settings.json은 claude 타겟을 설치하면
    .claude 폴더에 settings.json이 없으면 복사 있으면 해당 내용 비교 후 없는
    내용만 추가
  - codex 타켓을 설치한다면 packages/plugins/<name>/.cdoex/config.project.toml은
    .codex 폴더에 config.toml 없다면 복사 있으면 해당 내용 비교 후 없는 내용만
    추가
- docs는 claude를 제외하고 각 .claude/docs를 target에 맞게 링크 파일로 생성
- skills는 claude를 제외한 다른 타겟들은 .agents 폴더에 있으면 된다. (따로 생성
  하지말자)
- agents는 각 플랫폼에 맞게 폴더에 저장
- packages/plugins/<name>/폴더의 rules, hooks 폴더는 claude 타겟에만 복사한다.
